# v0.3.1 · 置入物体语义转写与 ChatGPT 工作模式

- 置入物体仍支持上传参考图；参考图先拆解为物体类别、外形、结构、材质、颜色、磨损与细节，并默认选中全部拆解项。
- 置入布局以原图为准，逐项描述前景、中景、背景、方位、尺度、遮挡、人物互动、支撑、接触阴影、投影、透视和景深。
- 最终提示词不再出现 `REFERENCE`、参考图 / 素材图编号、「与某图一致」或其他来源说明。
- ChatGPT 网页通道强制确认进入「工作」模式后才发送；支持沿用当前工作模型或指定 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Sol、GPT-6 Luna。
- 适配 ChatGPT 工作模式的新回复结构和完成状态，修复网页已分析完成但桌面程序收不到结果的问题。
- 旧版 ChatGPT 网页方案自动迁移为「工作 · 沿用当前模型」。
