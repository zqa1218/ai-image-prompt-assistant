# v0.3.5-patch.1

基于官方 v0.3.4 的增强补丁版。不新增功能入口，全部改动都落在原有流程里。

## 修复

**Gemini 网页通道**
- 对话 id 现在带运行标记：选一条线 / 载入存档即开新对话，原图重新上传
  （此前对话 id 只由原图指纹决定，同一个存档永远复用同一个对话，且附件指纹命中后不再上传原图）

**ChatGPT 网页通道**
- 页面偶发「无法加载 ChatGPT 模型」导致 composer 永久不可发送时，自动刷新自愈（最多两次），失败给出可照做的报错
- 附件计数改为只看 composer 范围，并要求无上传进度条、连续两拍稳定；解决「消息发出去了但没带图」
- 发送前后各加一道附件校验，缺图时明确报错而不是产出文字-only 的结果
- 读结果兼容新版 DOM（`data-message-author-role` 已消失，改用 `MarkdownRoot` 兜底）
- 工作模式的完成判定不再强依赖「回答已完成」文案

## 新增

- **置入物体 · 待定项**：细化阶段把待定参数列成 选项 + 推荐项，选完写进补充要求
- **反向拆解 · 确认点选项化**：把分析里的「需要用户确认的点」转成 问题 + 2~3 个互斥选项
- **资料收集（参考重构线）**：输入角色名与出处作品，AI 结合原图给出官方设定、2~3 个灵感方案、载入前确认项、检索关键词；可一键载入并跳到方向建议
- **合成模式 / 生成内容**两个必选项：大合成 / 半合成；纯净环境 / 带原人物（默认锁定脸·发型·服装·武器）。未选齐时资料收集按钮禁用
- **MJ 提示词四段式**：完整一行（可直接粘贴）＝ 正面 + 参数 + `--no 负面`，另有三块可分别复制
- **API 供应商快捷切换**：DeepSeek / MiniMax / 其它 OpenAI 兼容，一键填地址与模型

## 变更

- 最终提示词与复制内容统一剥离 `[cite: N]` 角标
- 参考重构线接收阶段新增「角色名称 / 出自作品 / 合成模式 / 生成内容」四个字段

## 资产

- `prompt-wizard-0.3.5-portable-win64.zip` —— 解压即用，与已安装版共用 `%APPDATA%\AI修图提示词助手`
- `app-patched.asar` —— 只替换 `resources\app.asar` 的精简版（16.1 MB）
