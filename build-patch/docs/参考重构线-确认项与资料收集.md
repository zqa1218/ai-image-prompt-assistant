# 参考重构线：确认项面板 + 资料收集（已实现并验证）

两件事都做完了，且都在真机跑通。累计 15 处补丁（E1–E15），产物仍是 `patch/app-patched.asar`。

![反向拆解的确认项面板](shots/confirm-panel.png)

## 1. 反向拆解的「需要你确认的点」

- 分析跑完自动把「需要用户确认的点」整段抓出来，一条一个勾选框
- 可补一句自己的确认，点「确认并进入方向建议」→ 写进 `notes` 并推进阶段
- 不勾也行，直接点原来的「下一步」，行为与改动前一致
- 解析放宽过：模型经常**不给编号**（纯段落），首版按列表标记解析会抓空，已改为按段落抓取

![资料收集面板](shots/research-panel.png)

## 2. 接收阶段的资料收集

位置：原图下面（两个字段插在字段数组开头，所以正好落在上传区之后）

- 输入 **角色名称** / **出自作品**
- 「让 AI 收集资料并给方案」→ 一次模型调用（约 25 秒）返回：
  - `character`：角色 + 出处 + 官方设定要点（例如「深紫发编者麻花辫」「左眼角下方细小美人痣」）
  - `inspiration`：2–3 个灵感方案，每个含「怎么改 / 为什么适合 / 适配的 MJ 参数」，带「用这个方案」
  - `confirm`：载入前要确认的 2–3 项，每项 2–3 个互斥选项并标推荐
  - `searchKeywords`：3–5 个找参考图的关键词（未做自动抓图，见下）
- 「载入并跳到方向建议」→ 把 `fill` 写回表单字段 + 已选的确认项写进补充要求 → 直接跳到方向建议并自动跑该阶段

验证：选「雷电将军 / 原神」后生成的方案里出现「中性灰纸 + 八角柔光箱 + 暗红金线刺绣丝绒」；方向建议的第一条就把确认项的选择（右手改为轻搭膝头裙摆）带进了「改什么」。

## 设计上的处理

你原本要求「载入后直接跳到方向建议」，但确认点是在**反向拆解**产生的，跳过去就看不到了。所以我把确认点做进了资料卡本身（`confirm` 字段），于是：

- 走资料收集：确认项在载入前就地选完 → 跳方向建议，不丢信息
- 不走资料收集：确认点在反向拆解面板里勾

两条路都不漏。

## 没做到的

- **参考图自动检索没做**。ChatGPT 的图片搜索没有稳定可抓的接口，硬抓要处理鉴权与外链，容易变成长期维护负担。现在给的是检索关键词清单，你自己搜一次即可。
- 资料收集面板放在**接收表单之前**（因为它在表单外面包了一层），所以是「原图 → 角色名/出处 → 其它字段」但按钮在更上方。要真正插到原图正下方，需要改 `Qd`（接收组件）内部结构，风险和收益不成比例。
- 角色名/出处目前只在「参考重构线」出现，原图精修线没加。
