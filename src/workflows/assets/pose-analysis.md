# 姿势优化 · 分析框架（精简版）

比精修线轻，只回答「现在是什么姿势、哪里不对、还能怎么动」。每项一到三句，只写画面里看得见的事实，不给修改建议。

## 1. 画面范围
- 先判死一件事：**全身 / 半身 / 特写**。
- 全身：脚是否在画面内、头顶与脚下各留多少空间。
- 半身：切在胯、腰、胸还是肩；有没有切到关节。
- 特写：以脸为主还是以手/道具为主。
- 人物占画面比例（大约几成高）。

## 2. 现状姿势（只描述，不评价）
- 躯干朝向：正对镜头 / 侧对 / 斜侧（约多少度）。
- 骨盆与肩线：是否平行、是否一高一低、有无扭转。
- 四肢：左右手各自位置（举、垂、扶、叉腰、持物）、肘与膝的弯曲程度。
- 支撑腿与重心：重心落在哪只脚、两脚分开多远、脚掌朝向。
- 持物：拿什么、握在哪、和躯干是否形成连线。

## 3. 动作问题（可观察的现象）
例如：躯干直立无扭转、重心落在两腿正中、肩线与骨盆平行导致呆板、手臂横伸切断躯干线条、四肢互相遮挡、两侧动作重复对称。
只说看得见的，不猜意图。

## 4. 场景与可动空间
- 环境类型、地面材质与是否平整、身前身后障碍物。
- 可用道具与其位置。
- **可动空间**：这个景别下腿能迈多大、手能抬多高、允许不允许多占画面。

## 5. 镜头与裁切
- 机位高度（平视 / 略高 / 略低）、俯仰。
- 透视强度、是否有广角变形。
- 裁切是否切到关节、是否适合改成更大幅度的动作。

## 6. 需要用户确认的点
最多两条。例如「是否可以接受改成坐姿」「是否必须保留持剑」。
