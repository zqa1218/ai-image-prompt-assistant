# 新增地台、手办台与环境物品的硬规则

仅在需求涉及「在人物脚下新增承重结构」或「在原环境里摆入可独立移除的道具」时启用。

## 先判定模式

1. **仅地台** —— 只新增人物脚下的承重结构
2. **手办台** —— 独立展示结构，含主承重地台、主视觉结构与辅助道具
3. **仅环境物品** —— 只在已有空间里摆放道具；禁止生成底座、平台、地面替换、墙体或完整建筑
4. **地台 + 环境物品** —— 地台承担人物重量，周边道具只作补充

用户说「只添加物品」「不要地台」「不改变原本环境」时，必须走第 3 种。

## 共通硬规则

- 人物身份、面部、发型、服装、饰品、身体比例、动作、姿态、特征、构图、镜头、画面比例、原始色调与光照方向全部保持不变
- 新增内容必须匹配原图的镜头高度、地平线、透视方向、人物比例、遮挡逻辑、景深、环境色、投影方向与光源软硬
- 所有结构与道具必须有明确支撑、重量、接触点与接触阴影；禁止悬空、穿模、错误缩放、错误透视、不合理堆叠
- 保留人物视觉中心，不得遮挡面部、关键服装、动作与脚部接触点
- 禁止随机文字、乱码、Logo、水印、重复复制模型、统一高光、过度锐化、粗糙笔触、脏乱噪点、廉价塑料感

## 地台

- 必须有可见厚度、边缘、侧面与承重逻辑，不能只是一张平面纹理
- 优先不规则结构：岩石、砖石台阶、木质平台、雪地、浅水岩面、工业地面、树根、建筑残片
- 默认避免规则圆形底座；仅当用户明确要求圆形、表盘、魔法阵或奖章式底座时才使用
- 鞋底、脚尖、衣摆与地台之间必须有正确的压迫、遮挡、接触阴影与受力关系
- 扩展遵循前低后高、左右错落，不能包围人物或遮挡下半身
- 真实表现材质：石材孔隙与崩角、木材木纹与接缝、金属焊点与氧化、冰水折射与裂纹、土壤颗粒与湿度

## 手办台

- 由主承重地台、一个主视觉结构、辅助道具与少量前景细节组成
- 主视觉结构只选一个核心（书堆、机械核心、树根、石柱、建筑残片、座钟、珊瑚、花架或展柜），不混入不相关的大主题
- 三层布局：前景低矮小物件 / 中景人物与承重结构 / 后景较高支撑物或轮廓物
- 必须有清晰独立边缘与完整轮廓，但不能无理由替换整个原始环境
- 主道具必须与人物、地台或相邻物件发生真实接触：倚靠、压住、放置、固定、插入或垂落
- 高密度不等于杂乱；重复物品必须改变大小、高度、方向、磨损与遮挡关系

## 环境物品

- 只添加可独立摆放和移除的道具：书籍、卷轴、花卉、器皿、文具、箱包、家具、小型灯具、独立屏风、武器收纳件、饰品、工具、科技设备、自然碎石、落叶、羽毛、纸张、冰晶、小型特效实体
- 禁止新增地台、平台、地面替换、整面墙、完整建筑、完整房间、天空替换与背景重绘
- 物品必须贴合原图已有的地面、桌面、家具、岩石、树根或建筑边缘，并有真实落点与投影
- 前景物品只能从画面边缘少量切入，并按原图景深自然虚化
- 后方物品只能使用低矮陈列件、小型家具、植物、灯具或道具组建立层次
- 只保留与用户指定主题直接相关的元素，删除泛化、串题、重复或会改变原环境的内容

## 真实材质与融合

- 石材：矿物颗粒、孔隙、崩角、风化、粗糙反射
- 木材：木纹、拼接、榫接、漆面、边缘磨损、受力变形
- 金属：厚度、接缝、拉丝、氧化、铆钉、正确环境反射
- 玻璃 / 水晶 / 冰：厚度、折射、色散、边缘高光、内部气泡或裂纹
- 纸张：纤维、厚度、折痕、卷边、装订、自然阴影
- 布料 / 丝带：织物纤维、褶皱、拉力、固定点、垂坠、边缘厚度
- 植物：根部、茎秆、叶脉、花瓣层次、含水状态、自然色差

任何光效都只能是次级元素：先表现真实物体本身，再加入克制的折射、微光、霜粒、火焰或粒子。禁止用烟雾、过曝或大面积发光覆盖材质细节。

当模式为「仅环境物品」时，提示词必须明确写出：只添加可独立摆放的物品，不新增地台、平台、地面替换、墙体、门窗、完整建筑或背景改造，严格保持原本环境不变。
