# 参考重构线：反向拆解与结构分层

原图在这里的角色是**参考与灵感**，不再是必须保留的事实来源。目标是产出「同一套语言、不同画面」的新图。

## 一、先分清参考图的职责

1. **人物身份参考**只回答「她是谁」，保持主要五官辨识度；目标画面接管妆容、发型、服装、场景、道具、光线与情绪
2. **摄影方案参考**只回答「这套图是怎么拍出来的」，不承担人物身份
3. 用户另外提供人物形象图但未说明用途时，只问一次：保持同一位人物，还是只借气质

## 二、人像参考的拆解要点

- 先判断**这张图为什么成立**，再写细节
- 光线必须写清来源、方向、在人物与环境中的落点，以及最终成像结果
- 更换机位时，光源、遮挡物与环境反射固定在世界空间中，先重建新视角下的受光关系，再编译提示词
- 风格写成可观察的成像机制，不用「高级、氛围感、电影感」代替白平衡、曝光、反差、高光、锐度、噪点、压缩与景深
- 穿搭只写服装，饰品归入道具；场景与道具分开
- 皮肤质感要区分**纹理**与**反射**；近景、直闪或高光妆面按景别控制底妆反射与高光范围
- 场景复杂度服从参考图的画面信息层级：先区分主体清晰区、主导大形、次级细节与低细节留白

## 三、通用结构层拆解

非人像或需要工程化描述时，按七层输出：

`主体 / 风格 / 光线 / 镜头 / 材质 / 构图 / 技术`

每层只写可观察事实，风格层必须落到成像机制，技术层写清后期倾向（颗粒、压缩、锐化、色偏等）。

## 四、只写可见事实

- 不确定的内容标「疑似」
- 不编造品牌、摄影师、器材或历史来源
- 只根据当前可见证据区分「事实」「强关联」与「灵感联想」

## 五、转成新画面时的纪律

- 新画面要继承的是**手法与语言**，不是原图的独特表达；避免照搬可识别的受保护内容
- 保留的是「为什么好看」，替换的是「具体画了什么」
- 输出前确认：主体、光向、构图三件事已经在新画面里被重新定义过，而不是原封不动
