# 原图精修线：模板选择与完整 Prompt 输出

## 一、先选模板

| 用户需求 | 模板 | 关键约束 |
| --- | --- | --- |
| 保留原场景，只升级质感 | 产品精修 | 主体保留；重点是质感升级而非替换；不强行换背景；不改产品形态与文字 |
| 整张换背景 | 换背景 | 必须重建主体边缘、遮挡与落在新背景上的投影关系 |
| 局部替换物件 | 局部替换 | 只动指定区域；其余区域逐像素保持一致 |
| 去杂物 / 去水印 | 物体移除 | 移除后补全的区域要延续原有的透视、材质与光照 |
| 人像局部修改 | 人像局部编辑 | 身份、五官、发型、比例不变；只改指定区域与相关光影 |
| 新增地台 / 手办台 / 环境物品 | 见 figure-base-rules 资产 | 承重、接触点、透视、材质按那份资产的硬规则执行 |

若需求跨多个模板，以「改动范围最小的那个」为主模板，其余作为补充写入修改项。

## 二、完整 Prompt 的六段逻辑

1. 声明 `REFERENCE_0` 与选区的编辑范围。
2. 锁定人物身份、未授权区域、原场馆、相机、构图和曝光。
3. 使用明确动词写具体修改对象、位置和目标结构。
4. 写清几何、相对比例、真实材质、遮挡、接触与景深层级。
5. 匹配底图的主光、环境反射、投影、颗粒、锐度与边界过渡。
6. 只加入本任务最容易出错的 4～8 条禁止项，并自然写入已有输出尺寸。

最终将六段逻辑合并成一条连续的中文自然语言 Prompt，不使用「保留项 / 修改项 / 禁止项 / 参数」标题，不保留占位符，不输出分析过程。

## 三、写完后的自查

- 修改项里的每个位置都能在原图上指出来吗
- 是否写清了接触点与接触阴影（新增物件最容易在这里穿帮）
- 光线方向是否与原图一致；若故意改变，是否已在修改项里说明
- 禁止项是否覆盖了本次最容易出错的点，而不是抄一遍通用清单

## 四、交付格式

`prompt` 字段只放一条可与底图、参考图一起直接提交给 Gemini / Nano Banana 的完整中文提示词；`channel` 字段说明附件顺序：底图 = REFERENCE_0，参考图按上传顺序 = REFERENCE_1...N。不要在提示词正文前后夹带额外说明段落。
