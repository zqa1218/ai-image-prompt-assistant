# 原图精修线：模板选择与四段式输出

## 一、先选模板

| 用户需求 | 模板 | 关键约束 |
| --- | --- | --- |
| 保留原场景，只升级质感 | 产品精修 | 主体保留；重点是质感升级而非替换；不强行换背景；不改产品形态与文字 |
| 整张换背景 | 换背景 | 必须重建主体边缘、遮挡与落在新背景上的投影关系 |
| 局部替换物件 | 局部替换 | 只动指定区域；其余区域逐像素保持一致 |
| 去杂物 / 去水印 | 物体移除 | 移除后补全的区域要延续原有的透视、材质与光照 |
| 人像局部修改 | 人像局部编辑 | 身份、五官、发型、比例不变；只改指定区域与相关光影 |
| 新增地台 / 手办台 / 环境物品 | 见 figure-base-rules 资产 | 承重、接触点、透视、材质按那份资产的硬规则执行 |

若需求跨多个模板，以「改动范围最小的那个」为主模板，其余作为补充写入修改项。

## 二、四段式输出骨架

```text
【保留项】严格保持 REFERENCE_0 中的人物身份、面部、发型、服装、饰品、身体比例、
动作姿态、构图、镜头位置、画面比例、原始背景与光照方向不变。

【修改项】在 <位置> 新增/替换 <内容>，以 <主体元素> 为核心，采用 <材质>，
具有 <真实细节表现>；在比例、透视、遮挡、接触点与接触阴影、材质反射、
投影方向和光影软硬上与原图自然融合。

【禁止项】不要出现随机文字、乱码、水印、Logo、重复复制、悬浮、穿模、
错误缩放、错误透视、过度锐化、塑料感。

【参数】输出比例 <x:y>，数量 <n>，编辑强度 <低/中/高>。
```

## 三、写完后的自查

- 修改项里的每个位置都能在原图上指出来吗
- 是否写清了接触点与接触阴影（新增物件最容易在这里穿帮）
- 光线方向是否与原图一致；若故意改变，是否已在修改项里说明
- 禁止项是否覆盖了本次最容易出错的点，而不是抄一遍通用清单

## 四、交付格式

先给一段可直接复制的中文提示词，再给一行「喂给谁」（Codex imagegen / GPT Image 2 / Nano Banana 等）。
不要在提示词前后夹带额外说明段落。
