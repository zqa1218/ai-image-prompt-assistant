# v0.2.5

- 「3.8 Flash · 对话」固定为默认网页方案：装好后不用调整，直接就是它；设置文件里出现未知方案名时也会回退到这个默认值，不再让设置接口报错。
- 新增「存档」：需求、底图、参考图整份存到本机数据目录，下次一键载入，不用重新选图、重新勾需求。支持命名保存、覆盖、删除，列表带底图缩略图。
- 多选字段（如「保持不变」）新增「全选 / 取消全选」和「清空」按钮，人物完全保持不变这类需求一键勾满。
- 存档存在本机 `%APPDATA%\PromptWizard\archives\`，只允许本机助手页面读写；单个存档最多 12 张参考图、图片总量 48 MB。
- 默认方案之外的选择仍然完全保留：网页方案、思考等级、以及其它对话方案都能照常切换。

验证：`tsc --noEmit` 通过、单元测试 145 项通过（其中新增多选、存档、载入存档用例），存档读写接口在本机服务上跑通增删查。
