## 桌面端与 Photoshop 联动版

### 怎么用

1. 运行 `AI修图提示词助手-0.1.0-x64.exe`
2. 第一次在「设置」页点击「登录 Gemini Pro」，完成 Google 登录
3. 打开 Photoshop；已安装的 Photoshop Link 会自动连接桌面助手
4. 从 Photoshop 导入当前合成画布，添加参考图并开始生成提示词

应用不需要 Gemini API Key。Google 登录态只保存在本机桌面应用的独立浏览器会话中；程序不会读取或保存 Google 密码。

也可以在「设置」页开启「演示模式」，用内置示例走完整流程，不访问 Gemini。

### 这个版本能做什么

- 两条工作路径：原图精修与参考重构
- 六步向导：接收、原图分析、方向建议、细化、生成提示词、迭代
- 原图固定为 `REFERENCE_0`，参考图依次为 `REFERENCE_1...N`
- 可从 Photoshop 导入当前文档的完整合成画布
- 将固定模板、本轮需求、底图和参考图打包提交到真实 Gemini 网页
- 等待网页生成完成并把回复自动回填向导
- 登录态持久化，后续启动无需重新输入账号密码

### 系统要求

Windows 10 / 11 64 位，Adobe Photoshop 2026（UXP 插件联动）。

### 关于 Gemini

每次生成都会把固定语言模板、本轮需求、底图 `REFERENCE_0` 和参考图 `REFERENCE_1...N` 一起提交到 `gemini.google.com`。全程不调用 Gemini API。

### 校验情况

- 单元测试覆盖工作流、图片角色顺序与网页请求编译
- 冒烟测试覆盖静态托管、目录穿越防护与桌面桥接错误提示
- 已实测 Gemini 网页文字往返与图片上传

### 说明

- 只有在你发起生成时，程序才会把当前任务与选中的图片提交到 Gemini 网页
- Midjourney 官方不提供 API，相关提示词仍需由你本人在官网或 Discord 界面提交
