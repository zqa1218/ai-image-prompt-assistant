## 下载解压就能用，不需要装任何东西

### 怎么用

1. 下载下面的 `ai-image-prompt-assistant-v0.1.0-win-x64.zip`（约 34 MB）
2. 解压到任意目录（请完整解压，不要只复制其中一部分文件）
3. 双击 `启动.cmd`
4. 浏览器会自动打开。第一次使用需要在「设置」页填入 API Key

> 压缩包名用英文是因为 GitHub 会清洗附件名里的非 ASCII 字符，中文名会被截断成乱码。
> 解压后的目录名、启动器和界面都是中文。

包里**自带 Node.js 运行时**，不需要安装 Node，也不需要 `npm install`。
API Key 只保存在解压目录的 `.env` 文件里，不会上传到任何地方。

没有 Key 也能先看看：「设置」页打开「演示模式」，用内置示例走完整流程，不调用任何模型。

### 这个版本能做什么

- **两条工作路径**
  - 原图精修线：原图是唯一事实来源，输出中文四段式编辑提示词（保留项 / 修改项 / 禁止项 / 参数）
  - 参考重构线：原图当参考与灵感，输出英文 Midjourney 提示词 + 参数矩阵 + 提交前清单
- **六步向导**：接收 → 原图分析 → 方向建议 → 细化 → 生成提示词 → 迭代。每步可回退，回退后下游结果自动作废并在界面上说明清了哪些
- **方向建议是可点选的卡片**：每张写清「改什么 / 成像结果 / 代价与风险 / 适配通道」，不选直接下一步会按推荐项继续
- **原图 + 参考图**：原图必填并统一称 `REFERENCE_0`，参考图可多张并按「参考图1」「参考图2」编号
- **风格迁移**：自动拆解参考图里可迁移的成分，按背景 / 元素 / 特效 / 光线 / 色调 / 材质六类列出，由你勾选要导入哪些，只有勾选的项会进入提示词
- **置入物体的放置方案**：所在层次、水平位置、远近、交互关系逐项可选；方向建议阶段会给出具体位置与依据（原图光向、留白分布、透视方向、主体朝向）
- **四段式分段渲染**：提示词按标记拆成独立区块，可整段复制，也可只复制某一段
- **成本可见**：向导底部显示本次会话的调用次数、输入输出 token、缓存命中占比与预估费用

### 系统要求

Windows 10 / 11，64 位。

### 关于模型

默认使用 DeepSeek `deepseek-flash`，它支持图片输入、1M 上下文与 JSON 输出。
在「设置」页也可以改成任意 OpenAI 兼容的服务（自定义 base URL + 模型名）。

### 这个版本做了哪些工程取舍

- **缓存前缀纪律**：请求固定为「system = 冻结资产，user = 变动内容」。实测同一前缀连发，缓存命中占输入约 90%，而未命中的部分正对应每次变化的用户消息。命中与未命中的输入单价差 50 倍，这条直接决定使用成本
- **思考模式按阶段开关**：该模型默认开启思考模式且强度为 high，交互式向导会慢到不可用，所以按阶段显式控制
- **结构化输出三级容错**：JSON 校验失败会重试一次，且第二次会追加一句「只输出 json 对象」——原样重发只在失败偶发时有用
- **图片格式归一**：不依赖文件扩展名或浏览器上报的 MIME，按文件头判断；不受支持的格式在浏览器内转码后再上传
