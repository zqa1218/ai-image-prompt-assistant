# v0.2.9

原图精修线 → 任务类型 → 厚涂修发。选择后显示「厚涂修发模式」：参考适配设计（默认）、参考严格复刻、已有结果局部优化、自由设计。

规则依据用户提供的《网感厚涂修发SKILL.md》和《AI学习文档网感厚涂修发.md》编写，集中在 src/lib/llm/hairTask.ts。按选择注入底图分析、参考拆解、方向建议、细化、生成及迭代；网页与 API 共用此路径。

规则包含主发束数量、束结证据、摄影几何、帽子与手臂遮挡、三层发丝质感、三句固定原文和按错误维度局部修正。没有参考时沿用底图现有结构，不虚构参考；当轮锁定项优先。文档的 text 代码框改为应用可解析的 JSON prompt 字段，保留专项分段和可复制正文。

使用：上传底图与头发参考图，选择厚涂修发，填写允许修改的区域和要保留的部分，依次分析、选方向、生成提示词。参考用途和用户锁定优先；自由设计必须主动选择或明确授权。

本次不迁移或删除存档。实际模型的视觉判断仍需用户检查，不承诺每次生成完全符合规则。
