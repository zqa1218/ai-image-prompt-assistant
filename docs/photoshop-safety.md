# 阶段 4：Photoshop 安全闭环

当前工作台版本 `0.4.0-dev.1` 已完成可离线验证的协议、坐标映射和结果回传链路。它仍是阶段 4 开发版：真实 Photoshop/PSD 验收和 Electron 主入口切换尚未执行。

## 数据边界

- UXP 面板每次加载生成新的 `sessionId`。读取和回传均携带 `requestId`、`sessionId`、`documentId`、文档名称及画布尺寸。
- 回传原文档前精确核对会话、文档 ID、名称、画布尺寸；回传原选区时还核对选区边界。任何变化都返回可操作错误，不退化到当前活动文档。
- COM 通道保持只读，只能列出和读取明确选择的文档；结果回传必须使用 UXP。
- UXP 写操作使用 `executeAsModal` 和单一可撤销历史步骤，结果始终成为新图层。临时图像在 `finally` 中删除。
- `fit_canvas` 和 `fit_selection` 保持结果宽高比并居中；`new_document` 创建独立文档。非零偏移选区使用完整裁剪偏移和缩放映射。
- 选区外接矩形只用于裁剪和定位。真实蒙版来自 `imaging.getSelection()` 的选择像素，并作为独立 `mask` 素材保存；没有选择像素时 `maskAssetId` 必须为 `null`。

## 使用

1. 启动 `npm run studio`。工作台会写入当前开发实例专用的 Photoshop bridge 描述文件。
2. 安装并加载 `apps/prompt-wizard-next/photoshop-plugin` 0.2.0。插件只连接回 `127.0.0.1` 或 `localhost`，使用随机令牌验证 WebSocket。
3. 在提示词候选中选择明确的 Photoshop 文档并读取。交换到工作台后，任务详情会显示目标文档指纹和真实蒙版状态。
4. 导入生成结果后，在结果卡选择“适配原画布”“适配原选区”或“新建文档”，再点击“回传 PS”。同一 `requestId` 重试不会重复建层。

## 已完成的离线验证

- 选区裁剪偏移、分析图到画布坐标反算、等比适配和居中。
- 会话重启、文档关闭/替换、重命名、画布尺寸变化、选区变化时拒绝回传。
- WebSocket 私有令牌、插件能力协商、状态请求合并、写操作串行、断线/超时错误。
- 任务/版本/结果归属检查和持久化幂等；没有 PS 来源的任务只能新建文档。
- Prompt Wizard 交换包保留 PS 指纹，并把真实 selection mask 与外接矩形分开。

## 真机验收闸门

必须由用户指定一个非工作测试 PSD，依次验证完整画布、非零偏移矩形选区和非矩形选区；再验证多文档、关闭重开、重命名、改画布尺寸、无文档、无选区、桥断线和撤销。全部通过前，不切换受保护的 Electron 主入口，也不宣称 Photoshop 闭环完成。
