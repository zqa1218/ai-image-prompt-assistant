# 当前功能地图（v0.6.9）

> 以 `codex/baseline-p0` 分支的实际代码为准。本文描述当前能做什么、数据保存在哪里，以及仍有边界的功能；早期阶段计划只保留为历史记录。

## 一、产品主流程

应用把底图、参考图和用户要求整理成可复制的图像编辑或生图提示词。一次任务固定经过六个阶段：

1. **接收**：选择底图、参考图，填写要求、约束和输出格式。
2. **分析**：识别原图事实层；参考图可进一步拆出可迁移项。
3. **方向建议**：给出多个方向，用户选择一个继续；未选时按推荐项继续。
4. **细化**：补充要求、回答待确认项，可按需生成资料、人设或参考图分工。
5. **生成提示词**：按当前线路的输出契约生成最终结果。
6. **迭代**：用自然语言继续修改结果，或开始下一张图。

回到上游阶段会作废受影响的下游结果；异步回复通过任务 ID 和提示词版本校验，避免旧回复覆盖新任务。

## 二、三条工作路径

| 路径 | 原图角色 | 最终产物 | 适合场景 |
| --- | --- | --- | --- |
| 原图精修线 | 唯一事实来源，要求尽量保持主体身份和未授权区域 | 一条完整中文或英文修图提示词 | 商品、人像、Cos 摄影后期、换背景、局部修改、置入物体 |
| 参考重构线 | 作为构图、角色或风格参考，允许生成不同画面 | 英文 Midjourney 提示词、参数和检查项 | 写真重构、海报、概念图、风格迁移 |
| 分步生成线 | 与精修线相同，但把新增内容按画面层级拆开 | 背景与陈设、身体互动、氛围层三段提示词 | 需要逐步生成、逐段复制和控制叠加顺序的任务 |

三条路径共用接收、分析、方向、细化、生成、迭代六阶段。分步生成线复用精修线字段与资产，只替换分析要求和最终输出契约。

## 三、一级页面与功能入口

### 向导

- 选择三条工作路径之一。
- 顶部切换 Gemini 网页、ChatGPT 网页或 API，并选择网页方案/推理等级。
- 接收页按“修图要求、约束、参考图、输出格式、资料与人设”组织输入。
- 支持任务快捷模板、精细字段、保持不变快捷标签、提示词正文语言和参考图引用方式。
- 底图必填，参考图可多张；每张参考图可单独填写用途说明。
- 可从本地选择图片，也可从 Photoshop 导入当前文档或选区。
- 每个阶段可回退、重跑；生成结果可继续对话迭代。
- 底部显示请求次数、token、缓存命中与预估费用。

### 存档和预设

- **存档**保存整套输入配置、底图和参考图，可载入、覆盖和删除。
- **提示词预设**保存当前产出文本，不带图片；支持搜索、预览、套用、撤回和删除。
- 存档与预设互相独立：删除来源存档不会删除已经保存的提示词预设。

### 资产

- 查看和修改工作流使用的固定提示词资产。
- 用户覆盖内容保存在本机，可恢复项目默认值。
- 资产参与缓存前缀构建，修改后会改变前缀哈希。

### 设置

- 开关演示模式；演示模式不访问模型，也不会读取图片内容。
- 配置 OpenAI 兼容 API 的地址、模型和 Key，支持供应商快捷预设及真实连通性检查。
- 登录或打开独立的 Gemini、ChatGPT 浏览器会话，并查看连接状态。
- API Key 由桌面端系统加密保存，不在前端回显。

## 四、输入与生成能力

### 图片

- 原图统一作为 `REFERENCE_0`；参考图按顺序编号。
- 浏览器侧把图片压缩到长边 1568 px，并校验实际文件头。
- 常见非标准输入会转成 JPEG 或 PNG；浏览器无法解码的格式会明确报错。
- Photoshop 有选区时导入选区外接框，无选区时导入完整画布。

### 任务组织

- 修图要求、任务类型、编辑区域、保持不变、置入位置、交互关系、效果来源和输出尺寸等字段按条件展示。
- 精修线支持中文或英文正文；参考重构线固定英文 Midjourney 输出。
- 参考图既可显式按“参考图 1/2”引用，也可消隐来源、只描述其视觉特征。
- 模型返回的方向卡片、待确认项和最终提示词优先走 JSON/结构化解析；失败时有容错、重试或原文降级。

### 结果处理

- 支持复制全文；分步或分段结果可单独复制。
- 支持导出 Markdown 和 JSON。
- 可把当前结果存成提示词预设。
- “复制并切到耀 AI”会先写入剪贴板，再尝试激活已识别的耀 AI 窗口；不会自动粘贴或提交。

## 五、模型与外部通道

| 通道 | 当前实现 | 主要边界 |
| --- | --- | --- |
| Gemini 网页 | 独立 Chrome/Edge 会话，自动上传附件、选择方案、复用同图对话并抓取文字结果 | 依赖网页 DOM，网页改版后需要实机回归 |
| ChatGPT 网页 | 独立浏览器会话，支持沿用当前模型或固定 Instant/Thinking/Pro 等档位 | 只抓取文字提示词，不负责生成图片 |
| API | OpenAI 兼容 `chat/completions`，默认 DeepSeek 配置，支持自定义供应商 | 单独计费；所选模型必须支持图片和当前消息格式 |
| 演示模式 | 使用本地假数据走通界面 | 不分析真实图片，不能代表模型质量 |

发送期间禁止切换通道或修改关键配置。Gemini 与 ChatGPT 的登录资料、对话映射彼此隔离。

## 六、桌面端与 Photoshop / 耀 AI

### Photoshop

- **COM 直连**：默认方式，不安装插件也能读取 Photoshop 文档和活动选区。
- **UXP 面板**：可选安装，面板主动连接本地服务；不要求日常打开 UXP Developer Tools。
- 两种方式只导出副本，不修改原 Photoshop 文档。

### 窗口能力

- 支持宽版/窄版切换、窗口位置与尺寸记忆、始终置顶和托盘找回。
- 可检测耀 AI 或 Photoshop 窗口并记录左右停靠目标。
- **窗口伴随仍是实验性功能**：当前已能识别目标、记录绑定和位置，但自动隐藏/自动收起尚未完整打通。
- 始终置顶与窗口伴随互斥，避免两个窗口策略争抢。

## 七、本机数据边界

| 数据 | 保存位置/方式 | 恢复范围 |
| --- | --- | --- |
| 临时会话 | 浏览器 `localStorage`，最长 7 天 | 只恢复线路和接收字段；图片与中间产物不恢复，并回到接收阶段 |
| 输入存档 | Electron 用户数据目录下的 `archives/` | 恢复输入、底图和参考图 |
| 提示词预设 | 浏览器 `localStorage` | 恢复一段产出文本，不带图片 |
| 自定义资产、布局偏好 | 浏览器 `localStorage` | 恢复资产覆盖、宽窄和置顶偏好 |
| API Key | Electron `safeStorage` | 系统加密保存，不向前端返回明文 |
| 网页登录与对话映射 | Electron 用户数据目录内的独立浏览器资料和映射文件 | Gemini 与 ChatGPT 分开保存 |

当前没有云同步、多用户协作或跨设备恢复。

## 八、当前边界与后续优先级

1. **先升级有安全公告的依赖**：生产依赖 `zod` 需要至少升级到 4.6.6；Electron、Vite、Vitest 等开发/运行依赖也有已知公告，升级后必须跑全量测试和桌面打包回归。
2. **先备份开发分支**：当前主要功能在 `codex/baseline-p0`，本地相对 `main` 已有大量提交，远端尚未发现同名分支。
3. **完成窗口伴随闭环**：目标窗口前台/后台、助手编辑、手动隐藏和跨屏 DPI 行为仍需真实耀 AI、Photoshop 联调。
4. **补真实通道回归**：自动测试覆盖核心逻辑，但 Gemini、ChatGPT 网页和 Photoshop/耀 AI 的外部状态会变化，发布前仍需实机验证。
5. **整理发布文档**：README 的安装包版本和部分阶段计划仍停留在旧版本；发布 0.6.9 前应统一版本号、安装方式和变更记录。
