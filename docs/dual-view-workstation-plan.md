# 双视图修图工作台改造计划（待用户确认）

## 目标与边界

完整工作台负责分析、方向选择、提示词对比与档案管理；窄伴随面板负责当前步骤、常用预设和耀 AI 交接。两者共享一个任务状态，不创建两份互相覆盖的任务。

本次仅归档现版与制定计划；用户确认前不改 UI、不迁移用户数据、不替换运行程序。借鉴修图轮椅的分类与渐进展开方式，不复制其代码、品牌资产或未经授权的预设。

必须保留：原图精修、参考重构、三步生成；每步独立优化；两阶段 API 方向选择；预览／采用／撤回；人物保留规则；自动去重入库；现有模型配置与安全存储。

## 推荐交互结构

| 视图 | 结构 | 主要动作 |
| --- | --- | --- |
| 完整工作台 | 左侧任务／三步导航，中间当前内容，右侧按需展开方向／约束／差异 | 看图分析、选方向、对比采用、管理档案 |
| 伴随面板 | 当前任务与步骤、输入图来源提醒、当前提示词、收藏／最近预设、交接按钮 | 复制当前段、打开耀 AI、确认步骤完成、展开工作台 |
| 预设库 | 搜索与分类、效果卡、详情抽屉 | 筛选、收藏、预览、应用到当前目标、导出耀 AI |

首版采用同一窗口的宽／窄模式切换，避免两个编辑窗口并发写入；伴随模式可选置顶，默认关闭，记忆窗口尺寸与位置并防止窗口移到屏幕外。暂不实现自动吸附 PS 或耀 AI 窗口。

宽模式以约 1100–1400px、窄模式约 360–420px 为原型起点，按 DPI 和可用屏幕自适应；窄模式不横向滚动。复杂优化点击后展开工作台，并返回原任务／步骤。首版用中性深灰与单一强调色，不用大面积炫光；中文使用本地系统字体，不依赖在线字体。

设计依据：UI/UX 检索的营销页模板不适用，因此不采用；采用检索中适用的键盘完整操作与可见焦点建议，其余为针对桌面工作流的设计提案。正文对比度至少 4.5:1，状态不只用颜色，图标有名称，错误就近展示，长标题可展开，主操作避免只依赖悬停。

## 分阶段实施及验收

### P0：建立可重建基线（必要前置）

- 对照当前 ASAR、补丁模块与旧源码，列出三条路径及历史改动差异，逐项迁回源文件。
- 将运行时／编译包补丁转成正式组件与服务模块，不在压缩 JS 上继续累积 UI 改动。
- 固定依赖与构建脚本；先验证现有行为等价，再开始视觉改造。
- 用户配置和档案先备份，迁移有 schema 版本且幂等；失败保留旧文件。密钥沿用加密存储，不写入前端持久化状态。
- 验收：干净环境可构建；三条路径、API 迭代、档案与预设的测试通过；旧存档可读取；明确新增编译文件哈希差异不等于功能差异。

### P1：双视图与状态统一

- 建立统一任务 ID、步骤 ID、提示词版本、输入图关联和执行状态；布局状态单独保存。
- 宽窄切换不丢需求、方向选择或未采用预览；同一任务同一目标的迟到 API 回复不得覆盖新版本。
- 关闭／重启可恢复已保存任务，未采用预览明确标记；本地图片缺失需重新关联，不假装已加载。
- 验收：三条路径往返切换至少 10 次状态不丢；缩放 100%／125%／150% 正常；键盘操作、错误、取消和恢复均覆盖。

### P2：效果预设卡与安全应用

- 分类：背景、陈设、身体互动、光效、氛围、清理；可追加人物部位标签，但不改变去人物化档案的默认用途。
- 卡片包括名称、短摘要、模式、适用条件、待复核／人工确认／出图验证状态；提供收藏与最近使用。
- 分步档案仍是一份档案，内部三步独立复制；预览后选择目标再应用，不直接覆盖。
- 首版参数化只给有明确语句映射的模板提供强度／色调等控件；不对任意旧文本自动猜测可调参数。
- 验收：搜索／分类／收藏可组合；长标题可读；套用可撤回；锁定人物与修改人物的矛盾会提示；旧档案无损升级。

### P3：分步执行与耀 AI 交接

- 状态：待准备 → 提示词已确认 → 已复制／已交接 → 结果待检查 → 用户确认完成。“复制成功”绝不等同于“生成成功”。
- 每步显示输入图来源及参考图顺序；改上一步后下游标记需复核，保留已有文本与结果。
- 增加耀 AI 专用词库导出：一段式一个词条，三步一个分组下的 01／02／03 词条；先用合成数据验证真实导入，避免重复分组与覆盖。
- 伴随面板提供复制和打开耀 AI；启动路径用户可确认／选择，不向任意程序传命令。
- 首版不自动粘贴、不点生成、不修改耀 AI 私有数据库。若需要自动填入，单独验证接口或 UI 定位并另行确认。
- 验收：实际登录后的耀 AI 导入与手动交接可用；不可用时保留复制／文件导出，不虚报联动成功。用户未登录则此项明确标为未验证。

### P4：验收与交付

- 使用模拟服务验证 API 约束、异常、取消、乱序回复、去重、密钥不泄露；真实付费测试需用户另行确认。
- 复测三条路径、三步独立优化、预览／撤回、档案搜索导出恢复、模型配置、升级迁移与回滚。
- 提供使用说明、版本说明、构建方式与备份恢复步骤；确认程序退出后才替换安装包。

## 不纳入首版

- 耀 AI 自动提交付费任务、自动取回图像与 PS 图层联动；其第三方接口尚未证实。
- 多任务并发生成、云端同步、多用户协作、自动导入他人商业预设。
- 全量效果图管理；首版可手动标记结果反馈，图片关联作为后续小版本。

## 待确认的推荐选择

建议批准 P0–P4 的上述范围：单窗口宽窄切换、可选置顶、保留现有三路径流程、先做导出与复制交接，不做自动付费闭环。先完成 P0 并展示双视图原型，再请用户确认布局后推进其余 UI 实现。如 P0 发现无法还原的历史补丁，提交差异与替代方案，不能默默丢弃功能。
