## 源码标签对齐版

这个版本的安装包与 **v0.2.0 功能完全一致**，是同一份源码重新构建的。

发布它的原因：v0.2.0 的标签停在 `dda32f5`，比实际编出安装包的提交落后 4 个提交，导致 Release 页上的
「Source code (zip / tar.gz)」下载到的是旧源码，和安装包对不上。v0.2.1 把标签、源码、安装包三者对齐。

如果你已经装了 v0.2.0 的安装包，**不需要升级**，功能没有任何差别。

### 本版本包含的改动

- **Gemini 会话改用真实 Chrome**：桌面端用独立的真实 Chrome / Edge 窗口打开 `gemini.google.com`，
  解决 Google 拒绝内嵌窗口登录的问题；按底图内容指纹绑定对话，分析、方向、细化、生成、迭代复用同一条
- **Photoshop 导图自动识别活动选区**：有选区导出选区外接框，无选区导出完整画布；UXP 面板与 COM 直连行为一致
- **允许多个 Photoshop 面板稳定连接**：服务器优先使用新版面板，避免旧 UDT 副本与安装版互相断线
- **流程末尾新增「下一张图」按钮**：一键开始下一轮，不用退回第一步
- **桌面端与 Photoshop 面板图标更新**，README 指向 Releases 里实际的安装包文件名

### 一键安装（推荐）

下载 `AI-Prompt-Wizard-Setup-0.2.1.exe`（安装后程序名显示为「AI修图提示词助手」），双击后一路到底，
全程只有一次 UAC 提权确认：

- 主程序装到 `C:\Program Files\AI修图提示词助手`，自动建桌面与开始菜单快捷方式，装完直接启动
- 自动把 Photoshop 面板 `com.promptwizard.photoshop-link` 写进本机所有 Photoshop 的 `Plug-ins` 目录，
  重启 Photoshop 后可在「窗口 > 插件」里看到
- 没装 Photoshop、或面板写入失败都不影响使用：助手还有不需要任何插件的直连通道读取画布
- 卸载时一并移除面板插件，但保留你的设置与对话记录

### 免安装便携版

`AI-Prompt-Wizard-Portable-0.2.1.exe` 双击即用；想用面板通道时，再执行一次仓库根目录的
`安装 Photoshop 面板（管理员一次）.cmd`。

### 系统要求

Windows 10 / 11 64 位。Gemini 网页模式需要本机装有 Chrome 或 Edge；Photoshop 联动为可选功能。
