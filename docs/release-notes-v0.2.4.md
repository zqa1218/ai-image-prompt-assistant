# v0.2.4

- 新增「4 Argon · 任务」备选，可在顶部「网页方案」选择。
- 一个方案只使用指定模型与模式，移除自动降级和跨模型重试。
- 无法确认模型/模式、未完成任务授权、收到短能力否认时明确报告失败。
- 切换方案会新建上下文并重新上传需要的图片，不混用其他方案的历史回答。
- 保留思考等级选择及现有四个对话方案。

本地待真机验证的模式确认修复：
- 支持成对的普通按钮及分段控件；读取控件自身或内部按钮的 ARIA 选中状态，不再只依赖外层 class。
- 控件延迟出现、切换重绘时等待最多 15 秒，连续两次确认；一次检查最多点击一次，不重复切换。
- 上传和填入提示词后再次只读核验所选模式及模型，不一致则不发送。
- 错误区分找不到开关、状态冲突、开关禁用、未选中及未稳定，不把无法识别当作成功。
- 本地模拟测试不能证明当前账号的真实网页结构已适配；仍需任务页实测后再发布。

验证边界：用户手动测试 Argon 任务模式的短文本修图提示词请求，反馈回复有效且速度快；完整图片上传、长模板与任务回复自动抓取尚未完成真机验证。历史降级链的成功结果不能证明某个指定模型成功，也不构成 100% 成功率保证。
